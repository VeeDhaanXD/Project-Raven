# Compliance Engine

Frameworks are versioned and applicability is entity-specific. Current demo registry includes NIST CSF 2.0, ISO/IEC 27001:2022 + Amd 1:2024, CIS Controls 8.1, CERT-In Directions 2022, RBI 2026 commercial-bank directions, SEBI CSCRF 2024 + 2025 clarifications, and DPDP Act/Rules metadata.

The UI uses evidence/assessment coverage, not a blanket "legal compliance %".
