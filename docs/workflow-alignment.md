# Workflow Alignment

The attached RAVEN workflow is preserved as the visual reference. The implementation aligns the principal flow as:

START → LOGIN → ORGANIZATION CONTEXT → DATA CONNECTORS → NORMALIZE → ASSET/VULNERABILITY/THREAT/CONTROL CONTEXT → RISK QUANTIFICATION → FINANCIAL RISK → AI DECISION SUPPORT → INVESTMENT OPTIMIZATION → SCENARIO / RESIDUAL RISK → COMPLIANCE / EVIDENCE → AUDIT → REPORT.

Role views correspond to the workflow's executive, technical, finance, auditor and regulator lanes. The implementation intentionally replaces fictional mission/quantum language with cyber-risk, evidence, financial and compliance terminology.
