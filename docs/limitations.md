# Limitations

1. Enterprise telemetry is synthetic for the demo.
2. Public intelligence is represented as cached snapshots in DEMO_MODE.
3. Regulatory mappings outside the cited/registry-backed claims need primary verification before production use.
4. The optimizer is exact for the demo-scale candidate set; an industrial solver should replace enumeration at larger scale.
5. No claim is made that demo estimates are correct for a real organization.
