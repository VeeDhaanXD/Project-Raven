# RBI

The current demo registry treats the Reserve Bank of India (Commercial Banks – Cybersecurity, Technology: Risk, Resilience and Assurance Framework) Directions, 2026 as an entity-specific framework versioned separately from other RBI directions.

Reference: RBI/DoS/2026-27/410, dated 31 July 2026. The application must select the right RBI instrument for the organization's entity profile.
