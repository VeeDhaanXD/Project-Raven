# Regulatory Applicability

RBI and SEBI are never treated as universal. An organization profile is evaluated against the entity type before a requirement is considered applicable. Non-applicable frameworks are stored as NOT_APPLICABLE with an explanation.

For RBI 2026, the commercial-bank instrument is versioned as RBI/DoS/2026-27/410 and should not be projected onto NBFC/UCB/payment-bank entities without the relevant framework record.
